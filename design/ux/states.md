# Voice-only Coach state matrix

Tier S — the existing one-control spoken lesson clarifies one derived, non-interactive activity readout; no new screen, flow, or control.

| Surface | Empty | Loading | Error | Partial | Success | Disabled |
|---|---|---|---|---|---|---|
| Instruction canvas | Blank until a real practice phrase exists; never invents a chat-like placeholder. | Retains the last real phrase while the spoken loop advances. | Oversized/invalid content is replaced by `Practice line unavailable.` in the same canvas and emits one categorical witness; no clipped prefix is shown. | Shows one current representation: pronunciation when supplied, otherwise the phrase. | Shows the exact current phrase or pronunciation target, with density adjusted in place. | Blank; disabling the lesson never adds explanatory copy. |
| Voice preset | `Choose voice`; pressing Start opens the same preset popover if none is selected. | Existing name remains visible while the library or upload is prepared. | Popover stays actionable; one concise error is announced and may appear in the recovery region. | Lists only valid, non-archived reference samples. | Displays the exact selected preset name; that preset is the tutor voice. | No silent fallback: a missing exact reference prevents the lesson from starting. |
| Session control | `Start`, centred at `66.667dvh`. | `End` during startup so the learner can cancel immediately; the separate activity readout shows `Getting ready…`. | Failed start returns to `Start`; failed end returns to `End`; concise recovery only, with the control still actionable. | `End` while capture is ready, hearing, coach-processing, or coach-speaking. | `End` throughout the live lesson; after learner shutdown completes it becomes `Start`. | The safe pre-bootstrap HTML begins disabled, then wiring enables it; no visible helper caption is added. |
| Activity readout | Hidden while stopped. | `Getting ready…` while microphone/session startup is unresolved or the active loop is briefly re-arming. | `Microphone unavailable.` replaces routine state for an input error/unsupported state; other concise actionable errors stay until a real recovery transition. Errors are the only politely announced statuses. | `Ready — speak now` only while capture is positively armed; `Hearing you` only after positive speech evidence; `Thinking…` for recognition/request/model work; `Speaking` only while tutor audio plays. | Returns directly to `Ready — speak now` when the next turn is armed; no success toast or history. | Hidden; never explains the Start/End control. |

Convention: one large, stable thumb target. `Start` and `End` are the only words ever placed on that control. The separate activity readout is a current instrument state, not conversation content or instruction. The learner—not the coach—owns both transitions, and a restart resumes the compact checkpoint without transcript or recorded-audio memory.

Activity priority: actual tutor audio → `Speaking`; input/question/task/coach processing → `Thinking…`; positive evidence for the current capture → `Hearing you`; positively armed microphone → `Ready — speak now`; active but not yet armed → `Getting ready…`; failed/unsupported input → `Microphone unavailable.` Transient phases may be skipped; the interface never adds delay just to display them. Routine activity is `aria-live="off"` so it cannot talk over the audible lesson; only an actionable error switches the same region to polite status semantics.

Instruction contract: a practice line is accepted through 120 normalized characters and a pronunciation spelling through 160. Supported content is rendered verbatim as one visible representation; the canvas changes only text density (`normal`, `compact`, or `dense`) to preserve the fixed viewport. It never writes an inline inverse scale, so browser and Android text enlargement remains real. Longer content fails visibly and atomically rather than being truncated or hidden.
