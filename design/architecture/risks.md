# Spoken turn pipeline — risks

## Risks

| risk | likelihood | impact | mitigation | spike? |
|---|---|---|---|---|
| Smart Turn misclassifies careful or synthetic voice-practice speech | M | H | never consult it before 1.8 s; treat it as advisory; keep a 4.5 s conservative fallback; stale decisions lose to resumed speech; collect categorical false-cut/over-wait feedback before retraining | PARTIAL — the 900 ms policy was falsified by a real human mid-thought prefix, then the deployed 1.8/4.5 s policy preserved a 1.2 s pause; representative physical-phone/stutter corpus proof remains |
| New worker dependency becomes brittle or unavailable | M | M | exact pins, exact model commit/SHA, isolated venv, supervised adapter, timeout, health, counted conservative fallback, removable interface | NO |
| WebSocket handler is attached but not reached due upgrade routing/auth | M | H | dispatcher-entry integration test through the real HTTP server; live capability advertised only when attachment succeeds; stitched liveSessionId witness | NO |
| End or coach handoff races a late semantic/ASR result | M | H | two-phase lease + backend session generation + segment finalization guard; End closes matching sockets and aborts ASR; kill tests stop during prediction and during ASR and refuse an old-lease reopen | NO |
| PCM buffering grows during extended deliberation | L | H | strict byte/duration cap; no disk writes; reject/close with one bounded error; clear on all terminal paths | NO |
| Status changes flicker or resemble a text conversation | M | M | one stable status line, short state nouns/phrases, no history, no transcript, reduced-motion support, phone screenshot/no-scroll gate | NO |
| Routine live-region updates talk over the audible tutor | M | M | visual routine state is not `aria-live`; only actionable errors use the existing polite announcement; deduplicate changes | NO |
| Remote Parakeet queueing causes occasional latency despite fast warm benchmark | M | M | record ASR provider duration separately from pre-ASR and total; bounded timeout; retain exact stage witnesses before further optimization | NO |
| Shared dirty worktree causes accidental overwrite | M | H | edit only scoped paths with patch-based changes; inspect diffs per file; never reset unrelated changes | NO |
| Selected reference is replayed or mixed with a generic voice identity | L after repair | H | reference is conditioning-only; Coach never attaches its URL to an audio player; exclude built-in profile description; require clone/generation/role/rate evidence at service, gateway, and browser; compare generated ASR/hash against reference; fail closed without substitution | YES — silent Pixel-route synthesis recovered the new target sentence exactly and differed from the 12 s reference hash/duration; perceptual identity remains human-unverified |
| Burst PCM silently overwrites the small browser ring buffer and cuts speech | L after repair | H | explicit consumed-sample backpressure; worklet refuses overflow; render final sample before `ended`; privacy-safe underrun/overflow witnesses; deterministic burst/tail kill tests | YES — 7,200 samples crossed a 4,800-sample buffer with no overfill or tail loss |
| Correct cloned TTS has slow uncached first audio | H | M | keep truthful `Thinking…`; cache unpaced synthesis; measure first-chunk and total separately; investigate native incremental VoxCPM streaming without weakening identity or tail gates | PARTIAL — corrected uncached proof was 5.85 s to first PCM; optimization remains |
| Technique-word emphasis remains too subtle despite intelligible pacing | M | M | renderer uses short clauses, punctuation, and one stressable technique word; fixed delivery is ~132 WPM; human audible turn is the acceptance gate | PARTIAL — GPU ASR was exact, but subjective stress needs human listening |
| Upstream TTS failure becomes clean partial EOF and advances coach continuity | L after repair | H | independent per-phase inactivity budgets; destroy begun response on timeout/error/cancel; frontend body rejection prevents `/voice/speech/played`; preserve gateway fallback against sparse frontend telemetry | YES — partial-body timeout/cancel tests reject instead of returning first-chunk success |
| Model load failure falsely self-attests cloned synthesis | L after repair | H | real model object is the readiness predicate; health/ready/generate fail 503; no production mock-audio branch; gateway rejects `mock-synthesis` | YES — no-model falsifier returns no audio/evidence and gateway mock-evidence test returns 502 |
| End or a stalled audio device leaves PCM playback unsettled | L after repair | H | abort rejects pump/completion/resume waits; stop is explicit; pending or rejected resume, capacity wait, and final drain are independently bounded; every path disposes | YES — three repeated queued End cycles, a real End during never-settling resume, an independent resume timeout, a short final-drain timeout, resume rejection, and no-consumption stall all settle with no played acknowledgement |
